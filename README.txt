สะท้อนผลการเรียนรู้ 3 บรรทัด
1. ได้เรียนรู้การสร้างเว็บเพจด้วยภาษา HTML และการใช้โครงสร้าง Semantic HTML อย่างถูกต้อง
2. ได้เรียนรู้การใช้งาน HTML Tags เช่น Heading, List, Table, Link, Image และ Form
3. ได้เรียนรู้การจัดโครงสร้างและนำเสนอข้อมูลให้เป็นระเบียบและเข้าใจง่าย โดยไม่ใช้ CSS และ JavaScript
